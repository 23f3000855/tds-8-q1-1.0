Financial Model Code


def calculate_growth(current, previous):
    """
    Calculates the growth percentage.
    """
    if previous == 0:
        return 0
    return ((current - previous) / previous) * 100

# Calculate Q3 Growth
growth = calculate_growth(115, 100)
print(f"Growth: {growth}%")

Financial Formula

We analyze the CAGR:

\[ CAGR = \left( \frac{EV}{BV} \right)^{\frac{1}{n}} - 1 \]

Where \( EV \) is ending value, \( BV \) is beginning value.
